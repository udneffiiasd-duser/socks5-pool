# socks5-pool

Менеджер **пула SOCKS5-прокси** с проверкой живости, ротацией и метриками.

## Возможности

- Периодическая проверка прокси (latency, статус)
- Ротация: round-robin и по наименьшей задержке
- Метрики: успешные/неуспешные соединения
- Потокобезопасность

## Сборка

```bash
go build -o socks5-pool .
```

## Пример

```go
pool := NewPool([]string{
    "127.0.0.1:1080",
    "127.0.0.1:1081",
})
pool.CheckAll(2 * time.Second)
p := pool.Best()
if p != nil {
    dialer, _ := p.Dialer()
    _ = dialer
}
```
